# Sumit Kumar — Personal Portfolio 🚀

Welcome to the repository for my personal portfolio website! This project showcases my skills, experience, and the projects I have built as a software developer & Full Stack Developer .

## 🔗 Live Demo
Check out the live website here: https://sumit-portfolio-six-iota.vercel.app

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS
- **Deployment:** Vercel
- **Styling & Animations:** Custom CSS, Tailwind, Scroll-driven animations

## ✨ Features
- **Interactive UI:** A scroll-driven character (avatar) that moves dynamically as you browse the page.
- **Skills Section:** A unique street-light and road themed design to display technical skills.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Projects Showcase:** Clean grid layout to display MERN stack projects with live links and GitHub repos.
- **Smooth Navigation:** Scroll-based animations and transitions using React hooks.
